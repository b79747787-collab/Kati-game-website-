# Kati Game Website

## Publish free with GitHub Pages

1. Create a GitHub account.
2. Create a new public repository, for example `kati-game-website`.
3. Upload all files in this folder.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**, choose `main` and `/root`, then Save.
6. GitHub will provide a public HTTPS address.
7. Replace `YOUR-DOMAIN-HERE` in `index.html`, `robots.txt`, and `sitemap.xml` with your real domain/address.
8. Add the site to Google Search Console and submit `/sitemap.xml`.

## Important
The leaderboard, accounts, challenges, tournaments, voice chat and live game features are currently placeholders. They require a backend/game server to become functional.
